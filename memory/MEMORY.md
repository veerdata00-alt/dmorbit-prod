# DMOrbit Memory System

# IMPORTANT

This memory system is NOT part of the DMOrbit product.

It exists solely for AI agents, developers, project documentation,
decision tracking, architecture understanding, audits,
deployment knowledge, and project continuity.

No production code, runtime logic, customer data,
campaign logic, Instagram automation, billing logic,
or user-facing functionality should ever depend on
this memory system.

The source of truth is always:
1. Live code
2. Production systems
3. Database state

The memory system is only an operational knowledge layer.
