# Product Principles

Create permanent product rules:
1. **Creator First**: Build for independent creators and small brands.
2. **Simplicity First**: If a feature requires a manual, it's too complex.
3. **Compliance First**: Always respect Instagram Graph API rate limits and Meta terms of service.
4. **Reliability Over Features**: A working core is better than a broken monolith.
5. **No Spam Automation**: We empower authentic connections, not bot farms.
6. **Campaign Terminology Preference**: Use "Campaigns" instead of "Automations" in all UX and messaging.
7. **Meta API Compliance**: Never use scraping or undocumented endpoints. Always use the official Graph API.
