# Quarterly Review Template

## Stale Documents
- List any files in `memory/` that no longer accurately reflect the codebase.

## Outdated Assumptions
- Did any market assumptions or product context shift?

## Architecture Drift
- Have we deviated from the architecture defined in `ARCHITECTURE.md`? E.g., introducing a new queue system or migrating to a different database.

## Cleanup Recommendations
- What tech debt can be removed?
- Are there abandoned feature branches or deprecated API endpoints to prune?
