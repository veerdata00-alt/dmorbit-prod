# Operational Memory Protocol

## Meaningful Session Updates
A memory update is **REQUIRED** at the end of a session only when:
- [x] Feature shipped
- [x] Major bug fixed
- [x] Architecture changed
- [x] Product decision made
- [x] Infrastructure changed

## Not Meaningful (DO NOT UPDATE MEMORY)
A memory update is **PROHIBITED** if the session only involved:
- [ ] CSS tweaks
- [ ] Small UI spacing
- [ ] Debugging attempts
- [ ] Temporary tests
- [ ] Failed experiments
- [ ] Minor refactors
- [ ] Console log changes
